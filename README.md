# Superpowers Todo Demo

Vanilla HTML/CSS/JS todo app built with the Superpowers workflow (brainstorm → plan → TDD → review).

## Run the app

ES module imports require a local HTTP server — opening `index.html` directly (`file://`) often fails in Chrome.

```bash
npm install
npm run serve
```

Open [http://localhost:3000](http://localhost:3000).

## Tests

```bash
npm test
```
